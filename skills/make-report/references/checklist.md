# Report checklist

Run this list at step 8. Each line names the rule it checks.

- [ ] Every item of `debrief`, "Before you send", holds (first sentence, asks, numbers, terms, not-checked list)
- [ ] The title states the answer, not a topic or a question (debrief, Shape)

- [ ] The summary runs 150 to 200 words, has no formulas or tables, and opens with the takeaway (standard.md, Front matter)
- [ ] The summary gives the question, the answer and what changes, with no recap of steps (standard.md, Front matter)
- [ ] Masses are in kg, never tons, which differ between unit systems (debrief, Numbers and evidence)
- [ ] Each cause not yet confirmed is labeled "hypothesis" (debrief, Numbers and evidence)
- [ ] Each claim says whether you checked it or someone else reported it (debrief, Numbers and evidence)
- [ ] Each figure and table has a number, a caption with unit and window, and a reference in the text (standard.md, Figures and tables)
- [ ] No figure repeats another figure or the text (standard.md, Figures and tables)
- [ ] No text refers to a figure by position, such as "the chart below" (standard.md, Figures and tables)
- [ ] Each figure pairs its colors with a second encoding (standard.md, Figures and tables)
- [ ] The report lists the data source and pull date, branch and commit, run ids, parameters, formulas and rerun command (standard.md, Body)
- [ ] Each improvement claim has its number, baseline, metric and window (standard.md, Body)
- [ ] Each source is linked at first mention, and each citation was checked against a primary source (standard.md, Body)
- [ ] Numbers in titles and prose come from the same tables as the figures (standard.md, Numbers in generated reports)
- [ ] The outcome block has all four fields (standard.md, Outcome block)
- [ ] Every variant section is present, or says "Not applicable" with a reason (the variant file)
- [ ] The lead sentence leads with the so-what, in plain field words (standard.md, Business language)
