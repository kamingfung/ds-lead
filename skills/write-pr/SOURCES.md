# Sources: write-pr

The wording of `write-pr` is new. This table says which idea, number or quote comes from which source. A quote is at most 15 words. The skill files carry no citations, so they stay short for the agent.

The rule "keep a PR small enough to review in about 30 minutes" is the author's own. No source here gives that number.
