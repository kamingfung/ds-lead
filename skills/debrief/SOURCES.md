# Sources: debrief

The wording of `debrief` is new. This table says which idea, number or quote comes from which source. A quote is at most 15 words. The skill files carry no citations, so they stay short for the agent.

## Where each source is used

| Idea, number or quote                                                                   | Where in the skill                             | Source                                                      | How used            |
| --------------------------------------------------------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------- | ------------------- |
| Give the answer first, then the reasons, then the ask                                   | Shape; Recommend, then support                 | Minto, _The Pyramid Principle_                              | idea, paraphrased   |
| Write each slide title as a full sentence; read alone, the titles tell the story        | Slides and storylines                          | Minto, _The Pyramid Principle_                              | idea, paraphrased   |
